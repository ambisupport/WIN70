# WN-70A Universal LED TV Remote (Android, IR)

Open this folder in Android Studio -> Sync -> Run on a phone with an IR blaster.
Or: Build > Build APK(s).

## Important
* Phone needs an IR blaster (ConsumerIrManager). Many Xiaomi/Redmi/Poco phones have one.
* Default key codes are PLACEHOLDERS. Long-press a key to enter your TV's real NEC address/command.
* FREEZE tap runs a key sequence (default MENU,1,1,4,7). Long-press FREEZE to change it
  to your TV's service-menu code (e.g. MENU,1,1,4,7 / 2,5,8,0 / RAW=00:XX ...).
